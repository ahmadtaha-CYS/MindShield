# MindShield 🛡️ (Work in Progress)

**Note: This repository is currently under active development as part of a Graduation Project.**

## 📖 About The Project
MindShield is an interactive web-based cybersecurity awareness platform designed to educate users about social engineering threats. The project addresses the growing impact of phishing, impersonation, and online scams by providing structured learning modules, scenario-based simulations, and quizzes with immediate feedback. 

Our goal is to improve users' ability to recognize and respond to social engineering attempts, thereby reducing human-related security risks.

## 🛠️ Built With
* **Front-End Development:** HTML, CSS, and JavaScript
* **Backend Services:** Firebase (Authentication, Firestore, Cloud Messaging, Storage)
* **Version Control:** GitHub

## ✨ Planned Features
Currently in development, the platform's scope includes the following core capabilities:
* User registration and login with secure authentication.
* Learning modules organized by topic with smooth navigation and content access.
* Scenario-based quizzes to assess understanding, with instant feedback and retake support.
* Progress tracking to display module completion and quiz outcomes.
* Completion status / certificate upon satisfying completion conditions.
* Role-based access control separating learner and administrator capabilities.
* Admin content management (modules, lessons, and questions) and reporting/analytics.

## 📐 System Design
The system architecture and requirements engineering have been fully documented, including:
